# Onboarding

## First Day Setup

1. Install Node.js LTS and npm.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and fill required values.
4. Run `npm run dev`.

## Validate Local Environment

- `npm run type-check`
- `npm run lint`
- `npm run test`

## Read Before First PR

- `docs/senior-md/engineering-standards.md`
- `docs/senior-md/scalability-and-operations.md`
- `docs/senior-md/agent-strict-rules.md`
- `CONTRIBUTING.md`

## First PR Expectations

- Small scoped change.
- Tests included/updated if behavior changes.
- All quality gates pass locally.
