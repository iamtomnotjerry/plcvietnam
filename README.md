# PLC Vietnam

Next.js + TypeScript codebase for PLC/SCADA industrial automation content.

## Quick Start

1. Install dependencies:
   - `npm install`
2. Configure environment:
   - copy `.env.example` to `.env.local`
3. Start local development:
   - `npm run dev`

## Quality Gates

- `npm run type-check`
- `npm run lint`
- `npm run test`
- `npm run validate`
